   - Wejdź na https://console.groq.com/keys, usuń wyciekły / stary klucz i wygeneruj nowy.
   - W terminalu skonfiguruj sekrety projektu Supabase:
     ```bash
     supabase secrets set GROQ_API_KEY=<twoj_nowy_klucz_groq> GEMINI_API_KEY=<twoj_klucz_gemini>
     ```
