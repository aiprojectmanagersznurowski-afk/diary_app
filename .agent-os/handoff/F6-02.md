# Handoff F6-02: Edge Function chat: przepisanie zapytania, wyszukiwanie i odpowiedź SSE z cytatami

Plik przekazania pracy między sesjami i agentami (Claude ↔ Gemini). Aktualizuj go na koniec
każdej sesji (workflow /os-handoff). Następny agent zaczyna od przeczytania tego pliku.

## Stan
- Zaimplementowano kompletną Edge Function `chat` obsługującą pipeline RAG:
  - `supabase/functions/_shared/schemas/chatQueryRewrite.ts`: schemat Zod walidacji ustrukturyzowanego zapytania (`search_query`, `date_from`, `date_to`, `kinds`, `categories`).
  - `supabase/functions/_shared/schemas/chatAnswer.ts`: schemat Zod dla cytatów i odpowiedzi czatu.
  - `supabase/functions/_shared/prompts/chat-rewrite.v1.md`: prompt do wyliczania bezwzględnych dat na podstawie relatywnych określeń ("wczoraj", "w tym tygodniu") i aktualnej daty/strefy czasowej, wyodrębniania filtrów typów dokumentów oraz słów kluczowych.
  - `supabase/functions/_shared/prompts/chat-answer.v1.md`: prompt asystenta RAG nakazujący odpowiadanie wyłącznie na podstawie `<context>`, oznaczanie źródeł formatem `[doc:<id>]` oraz uprzejme informowanie o braku wpisów w pamiętniku.
  - `supabase/functions/chat/types.ts`: interfejsy TypeScript dla request body, filtrów wyszukiwania, wyników chunków, cytatów, klienta bazy danych i zdarzeń SSE (`token`, `done`, `error`).
  - `supabase/functions/chat/queryRewrite.ts`: moduł przepisywania zapytań z obsługą strefy czasowej użytkownika oraz jednokrotną naprawą `repairCallback`.
  - `supabase/functions/chat/citations.ts`: moduł ekstrakcji cytatów z tekstu odpowiedzi, walidacji ID względem zwróconych chunków (eliminacja halucynacji) oraz formatowania `<context>`.
  - `supabase/functions/chat/dbClient.ts`: implementacja `IChatDatabaseClient` dla Supabase JS z weryfikacją JWT użytkownika, wywołaniem RPC `search_chunks`, zarządzaniem wątkami w `chat_threads` i zapisem wiadomości w `chat_messages`.
  - `supabase/functions/chat/index.ts`: punkt wejścia Edge Function ze strumieniowaniem protokołem Server-Sent Events (SSE).
  - `supabase/functions/chat/index_test.ts`: 12 kompleksowych testów Deno testujących CORS, walidację, 401, przepisywanie dat, naprawę schematu, ekstrakcję cytatów, odrzucanie halucynacji, pełny strumień SSE i obsługę błędów.

## Decyzje w trakcie
- Weryfikacja cytatów: cytaty `[doc:<id>]` wygenerowane przez LLM są ściśle filtrowane według identyfikatorów faktycznie pobranych dokumentów z `search_chunks`. Zmyślone identyfikatory nie trafiają do tablicy `citations`.
- Obsługa strumienia SSE: zdarzenia wysyłane są w standardowym formacie `data: JSON\n\n` ze zdarzeniami typu `token`, `done` (zawierającym `citations`, `thread_id` i `message_id`) oraz `error` w razie wyjątku.
