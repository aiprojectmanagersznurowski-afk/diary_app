# Handoff F1-05: Wylogowanie czyści stan aplikacji

Plik przekazania pracy między sesjami i agentami (Claude ↔ Gemini). Aktualizuj go na koniec
każdej sesji (workflow /os-handoff). Następny agent zaczyna od przeczytania tego pliku.

## Stan

Implementacja kompleksowego czyszczenia stanu aplikacji przy wylogowaniu ukończona i zweryfikowana:
- **Przypadek użycia (`src/application/useCases/auth/signOutUseCase.ts`)**:
  - Wylogowuje użytkownika z Supabase Auth przez `authRepo.signOut()`.
  - Resetuje stan in-memory każdego store'u Zustand: `useAuthStore.resetAuth()`, `useSettingsStore.resetSettings()`, `useGamificationStore.resetGamification()`, `useDiaryStore.clearEntries()`.
  - Czyści utrwalone stany w `AsyncStorage` dla persistowanych store'ów (`settings-storage`, `gamification-storage`).
  - Zawiera punkt rozszerzenia (`clearLocalQueue`) dla lokalnej kolejki nagrań (F2-01).
- **Store ustawień (`src/application/store/useSettingsStore.ts`)**:
  - Dodano metodę `resetSettings()` przywracającą domyślne ustawienia (`lifeGoals: []`, `theme: 'AppleDark'`, `aiPersonality: 'Po prostu przyjaciel'`) oraz usuwającą klucz `settings-storage` z `AsyncStorage`.
- **Store grywalizacji (`src/application/store/useGamificationStore.ts`)**:
  - Dodano metody `resetGamification()` i `clearGamification()` przywracające stan początkowy oraz usuwające klucz `gamification-storage` z `AsyncStorage`.
- **Store pamiętnika (`src/application/store/useDiaryStore.ts`)**:
  - Dodano metodę `clearEntries()` resetującą listę wpisów, błędy i flagi ładowania/nagrywania.
- **Store autoryzacji (`src/application/store/useAuthStore.ts`)**:
  - Dodano metodę `resetAuth()` zerującą obiekt użytkownika i flagi.
- **Ekran ustawień (`src/presentation/screens/SettingsScreen.tsx`)**:
  - `handleLogout` opiera się bezpośrednio na `authService.signOut()`, co gwarantuje spójne i atomowe wyczyszczenie całego stanu aplikacji.
- **Testy jednostkowe (`src/application/useCases/auth/__tests__/authUseCases.test.ts`)**:
  - Dodano precyzyjny test jednostkowy weryfikujący, że `signOutUseCase` resetuje wszystkie store'y do stanu początkowego oraz test wywołania punktu rozszerzenia lokalnej kolejki.
  - Wszystkie 24/24 testy przechodzą pomyślnie.
- **Bramki jakości (`gate.mjs`)**: `tsc` (0 błędów), `eslint` (0 błędów), `jest` (24/24 pass), `layers` (OK), `scope` (OK).
