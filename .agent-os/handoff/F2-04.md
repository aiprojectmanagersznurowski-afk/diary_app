# Handoff F2-04: Edge Function process-recording

Plik przekazania pracy między sesjami i agentami (Claude ↔ Gemini). Aktualizuj go na koniec
każdej sesji (workflow /os-handoff). Następny agent zaczyna od przeczytania tego pliku.

## Stan
- Zaimplementowano kompletną Edge Function `supabase/functions/process-recording/index.ts` obsługującą CORS, webhooki bazy (`{ record: { id } }`) oraz wywołania bezpośrednie (`{ recording_id }`).
- Zaimplementowano 5-krokowy idempotentny pipeline `supabase/functions/_shared/pipeline/processRecording.ts`:
  - Krok A: Transkrypcja STT (Groq Whisper), zapis `raw_transcript` (nigdy nie nadpisywany po zapisie), status `transcribed`.
  - Krok B: Podział na notatki LLM (Llama 3.3) z walidacją schema Zod i automatyczną naprawą, deterministyczny rendering Markdown zgodny z §5 (ADR-004), generowanie slugów odpornych na kolizje, zapis do Storage `documents` i tabeli `documents`, status `segmented`.
  - Krok C: Podział na chunki i generowanie embeddingów wektorowych (1536 dim, Gemini), zapis do `document_chunks`.
  - Krok D: Ocena powiązań między notatkami z filtracją dozwolonych ID kandydujących, zapis do `links`.
  - Krok E: Zapis dnia do kolejki przebudowy `day_rebuild_queue`, status `done`.
- Pełna idempotencja: ponowne wywołanie po błędzie wznawia od ostatniego kroku bez duplikatów. Błąd AI ustawia status `failed` z `last_error`, zachowując nagranie i audio.
- Warstwa abstrakcji bazy i storage: `supabase/functions/_shared/db/` (`types.ts`, `supabaseClient.ts`).
- Szablon Markdown: `supabase/functions/_shared/markdown/` (`noteTemplate.ts`).
- Testy: 42 testy Deno przechodzą bezbłędnie (`noteTemplate_test.ts`, `pipeline_test.ts`, `index_test.ts`, `validate_test.ts`, `factory_test.ts`, `retry_test.ts`, `groq_test.ts`, `gemini_test.ts`). Eslint (0 ostrzeżeń), tsc (0 błędów), testy jednostkowe Jest (54 passed).
